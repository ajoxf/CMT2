# Chart Images for CMT Exam

## How to Add Images

1. **Save chart images** from the PDF as JPG or PNG files
2. **Name them** using this format: `question-[NUMBER].jpg`
   - Example: `question-9.jpg`, `question-10.jpg`, etc.

3. **Place them** in this folder (`/images/`)

## File Format

Recommended:
- **Format**: JPG or PNG
- **Size**: Maximum 1200px width (for fast loading)
- **Quality**: Medium (60-80% for JPG)
- **Naming**: All lowercase, use hyphens

Example filenames:
```
question-9.jpg
question-10.jpg
question-17.jpg
question-35.png
```
