# 🚀 Quick Start Guide

## Get Your CMT Exam Online in 3 Steps!

### Step 1: Complete the Questions (2-3 hours)
1. Download all files
2. Open `questions.js` in any text editor
3. Add questions 21-150 using the template provided
4. Use the answer key in `DEPLOYMENT.md`

### Step 2: Push to GitHub (5 minutes)
```bash
git init
git add .
git commit -m "CMT Level II Exam"
git remote add origin https://github.com/YOUR_USERNAME/cmt-exam.git
git push -u origin main
```

### Step 3: Deploy to Vercel (2 minutes)
1. Go to [vercel.com](https://vercel.com)
2. Click "New Project"
3. Import your GitHub repo
4. Click "Deploy"
5. ✅ Done!

## 📱 Your Exam Will Be Live At:
`https://your-project-name.vercel.app`
